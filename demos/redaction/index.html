Working demo

Take the person out. Run the AI. Put the person back.

The safest way to use AI on records about real people is to make sure the AI never sees who they are. This page does that in four steps, and you can try it with your own text.

Everything here runs inside your browser. Nothing you type is sent anywhere, and no AI is connected to this page. The people in the samples are invented.

1The original text

Pick a sample or paste your own. The list on the right is the people you already know are in your records, such as a class roster or a staff list.

2What the AI is allowed to see

Rules written in code swap each identifying detail for a placeholder. Then a gate checks what is left. If anything still looks like a person or an ID, the text does not go out.

3The AI does its work

Copy the safe version into Claude, Copilot or any assistant and ask for what you need. Paste its answer below. For the samples, an answer is already filled in.

4The real details go back in

The key turns each placeholder back into the real value, on your computer. If the answer contains a placeholder that was never issued, it is flagged instead of guessed.

Why it is built this way

Four decisions behind the demo.

Code decides what is identifying, not a model

The swap is done by fixed rules and a list of known people. Asking an AI to find the private details would mean showing it the private details first.

The same person always gets the same placeholder

"Amara Osei" and a later "Amara" both become the same placeholder, so the AI can still follow who did what. It reasons about the case without knowing whose case it is.

The gate assumes the rules missed something

Rules and lists cannot know a name they have never seen. So a second check looks for anything name-shaped or number-shaped that survived, and stops the text until a person decides.

The key stays local

The table that maps placeholders to real values is never sent with the text. Without it, the safe version cannot be turned back into a record about anyone.

What this demo does not catch

Street addresses, and names it has no reason to suspect, such as a single uncommon first name in the middle of a sentence. The next layer I would add is a small name-finding model that runs on the same computer, with these rules kept as the backstop.
